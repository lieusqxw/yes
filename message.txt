Вопрос: Объясните, что делает следующий SQL-запрос. Какой класс ошибок данных он выявляет? Что означает HAVING COUNT(*) > 1?

sql
SELECT last_name, first_name, city,
       COUNT(*) AS количество,
       GROUP_CONCAT(id, ', ') AS id_list
FROM customers
GROUP BY last_name, first_name, city
HAVING COUNT(*) > 1;
Ответ:
Запрос ищет дублирующиеся записи в таблице customers по комбинации полей last_name, first_name, city. Для каждой такой группы подсчитывает количество дублей (COUNT(*)) и собирает через запятую все id дублей (GROUP_CONCAT).
Класс ошибок: избыточность / неконсистентность данных (должно быть уникально, но есть повторы).
HAVING COUNT(*) > 1 – фильтрует группы, оставляя только те, где количество записей больше 1 (т.е. есть дубликаты).

sql
SELECT c.id,
       c.last_name || ' ' || c.first_name AS клиент,
       c.email,
       c.city

LEFT JOIN orders o ON o.customer_id = c.id
WHERE o.id IS NULL;

Вопрос: Объясните назначение данного SQL-кода. Что такое триггер? Что означают ключевые слова AFTER UPDATE, FOR EACH ROW, OLD, NEW?

sql
CREATE TRIGGER trg_log_price_update
AFTER UPDATE ON products
FOR EACH ROW
BEGIN
    INSERT INTO event_log (table_name, operation, record_id, old_value, new_value, event_time)
    VALUES ('products', 'UPDATE', OLD.id,
            CAST(OLD.price AS TEXT),
            CAST(NEW.price AS TEXT),
            datetime('now'));
END;
Ответ:
Триггер – это автоматически выполняемое действие при определённом событии в таблице.
AFTER UPDATE – срабатывает после обновления строки.
FOR EACH ROW – выполняется для каждой изменённой строки.
OLD – значения полей строки до изменения (доступно в UPDATE, DELETE).
NEW – значения полей после изменения (доступно в INSERT, UPDATE).
Код создаёт триггер, который логирует изменение цены товара: записывает в event_log старую и новую цену.

python
import sqlite3

def create_connection():
    conn = sqlite3.connect(':memory:')
    conn.row_factory = sqlite3.Row
    conn.executescript("""
        CREATE TABLE customers ...
        INSERT INTO customers ...
    """)
    return conn

conn = create_connection()
rows = conn.execute("SELECT * FROM customers").fetchall()
for row in rows:
    print(row['last_name'], row['city'])
conn.close()
Ответ:
Код создаёт БД в оперативной памяти (:memory: – база существует только пока открыто соединение), устанавливает row_factory = sqlite3.Row, что позволяет обращаться к колонкам по имени (как к словарю), выполняет скрипт создания и заполнения таблицы, затем выбирает все строки и выводит фамилию и город. row['last_name'] – доступ по имени колонки.

Вопрос: Объясните данный SQL-запрос. Что такое «ошибка ссылочной целостности»? Зачем используется LEFT JOIN вместо обычного JOIN?

sql
SELECT oi.id        AS item_id,
       oi.order_id,
       oi.product_id,
       p.name       AS product_name
FROM order_items oi
LEFT JOIN products p ON oi.product_id = p.id
WHERE p.id IS NULL;
Ответ:

LEFT JOIN нужен, чтобы включить все строки order_items, даже если нет соответствующего товара; для таких строк поля products будут NULL. Затем WHERE p.id IS NULL отсеивает только те, где товара нет. Обычный INNER JOIN не показал бы такие строки.

sql
CREATE INDEX idx_orders_customer_date ON orders(customer_id, order_date);

EXPLAIN QUERY PLAN
SELECT * FROM orders WHERE customer_id = 1 AND order_date > '2024-11-01';

EXPLAIN QUERY PLAN

Ответ:
Составной индекс – индекс по нескольким колонкам. Он эффективен для поиска по левому префиксу (начальным колонкам). В данном индексе сначала идёт customer_id, затем order_date. Поэтому фильтр по customer_id использует индекс (первая колонка), а фильтр только по order_date – нет, потому что order_date не является левым префиксом (индекс не может быть использован).

def generate_dump(conn):
    lines = []
    tables = conn.execute("SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%'").fetchall()
    for (table_name,) in tables:
        ddl = conn.execute("SELECT sql FROM sqlite_master WHERE type='table' AND name=?", (table_name,)).fetchone()[0]
        lines.append(f'\nDROP TABLE IF EXISTS {table_name};')

    return '\n'.join(lines)
